One row per feature, one column per role. Turn a cell on to let that role use the feature: its pages appear in their sidebar and its API calls are accepted. Turn it off and the entry disappears, the page goes back to their dashboard, and the API rejects the action even if the page is opened directly. Cashier access can be granted feature by feature — for example Menu & products lets cashiers use the menu while billing. Accounts already signed in pick the change up on their next page load. Super administrators are not part of this matrix.
